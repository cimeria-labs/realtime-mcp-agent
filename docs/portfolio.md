## Pinned Repository Blurb

Realtime MCP Agent is a safety-first local automation foundation. The public code implements a TypeScript tool router, allow/block/confirm policy decisions, sandboxed filesystem writes, and mock desktop/browser adapters. Live Realtime voice and real MCP adapters are documented roadmap items, not current claims.

## Resume Bullet

- Built a TypeScript tool-routing and safety-policy foundation for local AI automation, validating named tool calls with Zod, enforcing allow/block/confirm decisions, restricting filesystem writes to a sandbox, and documenting a roadmap toward Realtime voice and MCP adapter integrations.

## LinkedIn Project Summary

This project explores how local AI agents can be made safer by routing every tool request through explicit schemas, policy checks, and narrow adapters before any desktop, browser, or filesystem action is attempted.
